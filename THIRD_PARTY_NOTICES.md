## Detectors (demo)

The webcam demo uses YOLO-World v2 / YOLOE / YOLO26 detectors built on **ultralytics**
(**AGPL-3.0**). Detector weights are **not** part of the RelSGG release artifacts
(the Apache-2.0 code and the DINOv3-licensed relation checkpoints). They are shipped
separately, and only there:

* The public **browser demo** (github.com/Maelic/RelateAnything_demo, served at
  maelic.github.io/RelateAnything_demo) hosts ONNX exports of `yoloe-11s-seg(-pf)`,
  `yolov8s-worldv2` (re-parameterized to RA-4M-497) and `yolo26n/s` as separate
  model files under **AGPL-3.0**, listed in that repo's `THIRD_PARTY.md`. The page
  loads them at runtime; the corresponding source is ultralytics at the version
  named there plus `deploy/web/export_web_models.py` here.
* Everything else (laptop bundles, HF release) still rebuilds locally:

      deploy/reparam_detector.py        # re-parameterize to the RA-4M-497 vocabulary
      deploy/export_detector_onnx.py    # export the reparameterized detector to ONNX

Users of either path are bound by AGPL-3.0 for the detector component. The RelSGG
relation model does not link against ultralytics at inference time (numpy +
onnxruntime / onnxruntime-web only). The MobileCLIP-BLT text tower used to
re-parameterize YOLOE is likewise only distributed with the browser demo, under
Apple's MobileCLIP weights license.
