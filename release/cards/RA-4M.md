# RA-4M: 4.3 million free-text relations, geometrically verified

RA-4M is the training corpus of **RelateAnything**
([code](https://github.com/Maelic/RelateAnything) · paper: *RelateAnything:
Real-Time Open-Vocabulary Relation Prediction From Any Inputs*). Each
relation is a `(subject box, predicate, object box)` triple with a free-text
predicate, generated by a vision-language model against drawn, numbered boxes
and then filtered by a deterministic geometric check.

| | train | val |
|---|---|---|
| images | 474,413 | 24,964 |
| relations | 4,282,531 | 226,203 |
| relations per image | 9.03 | 9.06 |
| distinct predicates | 10,102 | 2,222 |
| spatial share | 48.5 % | 48.4 % |
| predicate entropy (nats) | 3.99 | 3.99 |

Annotator: `google/gemma-4-26B-A4B-it` through vLLM, three passes per image
(semantic, grow, spatial), about 110 GPU hours in total. The prompts are in
`prompts/`. The generation pipeline, gates and statistics scripts are in
[`datagen/`](https://github.com/Maelic/RelateAnything/tree/main/datagen).

**Synonyms are never collapsed.** `riding` and `riding on` are separate
predicates. Surface-form diversity is part of the label space of an
open-vocabulary model; canonical groups exist only so that a synonym is never
scored as a negative during training.

## Images

The images are those of MegaSG
([JosephZ/mega_1m](https://huggingface.co/datasets/JosephZ/mega_1m)): an
Objects365 / OpenImages / COCO re-crawl (282,802 / 189,856 / 27,342 of the
500,000 images in the manifest). **Images are not redistributed here.**
`images/ra4m_image_manifest.tsv.gz` lists every image
(`split, coco_image_id, file_name, original_id, source, width, height,
num_relations, in_megasg_clean`) and `images/extract_from_mega1m.py`
streams the upstream shards and writes exactly this image set to disk.

## Files

| path | contents |
|---|---|
| `annotations/ra4m_train.jsonl.gz`, `annotations/ra4m_val.jsonl.gz` | one record per image (format below) |
| `annotations/*.stats.json` | corpus statistics, gate drop counts, GPU hours |
| `images/` | image manifest, file-name list, extractor script |
| `prompts/` | the three generator prompts, verbatim |
| `packs/megasg_clean/train/` | the training pack (463,657 images after the leakage audit), memmap format read by `data/relation_dataset.py` |
| `packs/vg_raw/train/` | raw Visual Genome relations pack (CC BY 4.0), mixture partner |
| `packs/hicodet/{train,test}/` | HICO-DET verbs pack, mixture partner |
| `packs/megasg_proxy50k/` | 50k-image proxy pack for smoke runs and ablations |

### Record format

```json
{"img_id": 89866, "split": "train", "file_name": "objects365_v2_02198033.jpg", "n_objects": 4,
 "relations": [
   {"subject_id": 3, "subject_label": "person", "predicate": "holding",
    "object_id": 1, "object_label": "cymbal", "round": 1},
   {"subject_id": 1, "subject_label": "cymbal", "predicate": "below",
    "object_id": 2, "object_label": "microphone", "predicate_raw": "above",
    "round": 3, "spatial": true},
   {"subject_id": 1, "subject_label": "cymbal", "predicate": "above",
    "object_id": 4, "object_label": "person", "spatial": true, "source": "geometric"}]}
```

`subject_id` / `object_id` index the MegaSG boxes of that image
(`coco_image_id` in the manifest joins to `_annotations.coco.json`).
`round` is the generation pass (1 semantic, 2 grow, 3 spatial);
`predicate_raw` is the string before direction was fixed by the role-swap
check; `source: geometric` marks the deterministic spatial back-stop added to
images below the spatial-density floor. Object labels are provided for
convenience only. RelateAnything never receives them as input.

## Build the training packs yourself

```bash
python datagen/export_coco_sgg.py --split train      # jsonl -> COCO scene-graph json
python training/pack_megasg.py --dataset megasg      # COCO json + images -> memmap pack
```

See [`docs/data.md`](https://github.com/Maelic/RelateAnything/blob/main/docs/data.md).
