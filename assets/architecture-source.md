# Architecture figure

`architecture.png` is Figure 2 of *RelateAnything: Real-Time Open-Vocabulary
Relation Prediction From Any Inputs*, arXiv:2609.12552v1, page 7.

Source: https://arxiv.org/pdf/2609.12552v1
Author: Maëlic Neau. License: CC BY-SA 4.0, as stated on
https://arxiv.org/abs/2609.12552v1.

The figure is reproduced without changes; page text and the caption are cropped
away. Rendered at 300 DPI with Poppler:

```bash
pdftoppm -f 7 -l 7 -r 300 -x 283 -y 300 -W 1971 -H 940 \
  -singlefile -png paper.pdf assets/architecture
```
